# 鲸鱼搓澡店 · Whale Spa（试玩 Demo）

帮你把鲸鱼身上的**藤壶**切干净的小游戏。切一个藤壶 = 1 金币，金币拿去换**更大更快的刀**。
一只鲸鱼清干净后它会开心地挥手道谢、游出屏幕，下一条鲸鱼接着来。

---

## 怎么玩

**直接双击打开 `index.html` 就能玩**（Chrome / Edge 都行，不需要装任何东西、不需要联网）。

操作：

| 操作 | 说明 |
|---|---|
| 移动鼠标 | 瞄准（十字准星） |
| 鼠标左键 | 出手 |

规则：

- 左上角显示**第几关 / 还剩几个藤壶 / 当前武器 / 连击数**
- 右上角是**氧气条** + **金币** + **音效开关**（🔊/🔇）
- 每切掉一个藤壶掉金币，金币自动飞进钱袋
- **连击**：短时间内连续切掉多个有额外金币
- 鲸鱼清干净后：它冒出星星消失，**变身成角色登场道谢**，然后离开屏幕，下一条鲸鱼接着来
- 之后自动弹出**商店**：换武器、买特质、买道具
- 商店商品变多了（7 把武器 + 4 个特质 + 5 个道具 = 16 张卡），面板**超出屏幕时可以滚动**：
  鼠标滚轮、上下方向键、PageUp/PageDown、Home/End 都能用；底部按钮固定在面板下方，不会被挤掉

## 存档

- 进度**自动保存在本机**（`localStorage`），关掉浏览器再打开还在
- 存的内容：金币、当前武器、道具等级、已买特质、最高关卡、音效开关
- 标题页会显示存档摘要，可以选 **「继续上次的进度」** 或 **「开始新游戏」**
- 商店和标题页都有 **「删除存档」**
- 存档坏了 / 版本旧了 / 浏览器禁用了存储，都会**安全降级**（游戏照常能玩，只是不存档），不会崩

## 素材是怎么来的

游戏里的东西全部是**程序生成或从你给的两张图里算出来的**，没有外部素材、没有联网请求：

| 东西 | 来源 |
|---|---|
| **鲸鱼本体** | **你最后给的那张透明 PNG**（1024×778，自带 alpha 通道），直接内嵌进 `js/assets.js` 当贴图用 |
| **藤壶** | 我**自己画**的：程序化生成的火山状贝壳，带放射脊、锯齿开口、随伤害出现裂纹。分 4 种（小/中/大/簇），尺寸和形状每次随机 |
| **藤壶贴的位置** | 用鲸鱼的矢量轮廓算出 **252 个合法落点**，并逐个验证「整个藤壶都在鲸鱼身体里」，所以藤壶绝不会飘在水里，也不会盖住肚皮、眼睛、鼻孔 |
| **手（拆出来的独立素材）** | 从人物资产图里抠出来：按肤色/金边找连通域，得到左右两只小拳头（各约 48×46px），存成 `assets/hand-a.png`、`hand-b.png`（目前备用） |
| **清干净后的形态** | **第一张 Q 版女仆立绘**（按你最后的要求换回这张；白底保留，画成圆角道谢卡片 + 随机感谢台词） |
| **商店/标题头像** | 同一张 Q 版立绘 |

### 清干净之后会发生什么

1. 最后一个藤壶消失 → 鲸鱼冒星星、缩小消失
2. **换成人物的资产图**（你给的那张，白底按要求保留），放进一张圆角卡片里，轻微呼吸浮动
3. 冒出**感谢的话**（随机一句，每 1.2 秒换一句）：
   - 谢谢你帮我清干净啦～
   - 哇！身上轻多了，好舒服！
   - 这些藤壶痒了我好久，谢谢！
   - 你刀法真好，下次还找你！
   - 谢谢你～这是我的小小心意！
4. **人物往右加速离开屏幕**（约 1.4 秒）
5. **下一条鲸鱼自动从左边游进来**，身上带着更多藤壶，直接可以继续切
6. 新鲸鱼到位后**自动弹出商店**结算，可以换刀换道具
7. 点「下一条鲸鱼 →」继续下一关，循环下去

### 两张图的处理方式（按你的要求）

| 图 | 处理 |
|---|---|
| **鲸鱼** | 用你**最后给的那张透明 PNG**（1024×778，已自带 alpha）。它的鲸鱼宽高比 1.3162 和我原来描的矢量路径 1.3082 基本一致（确认是同一只），所以藤壶落点坐标可以直接对齐，精准贴在身上 |
| **Q 版女仆立绘** | **白底保留，不动**，只裁掉多余空白并缩放到 440 宽。画的时候套一张圆角白卡，看起来是刻意的"道谢卡片" |
| 另一张踢腿角色图 | 已归档在 `whale-brand-kit/assets/source/dafeiyu-kick.png`，**本次不使用**，需要时可随时切换 |

> 如果你希望女仆立绘去掉白底直接贴在水里，告诉我一声就行。

## 目录结构

```
whale-game/
├── index.html          游戏页面（双击这个）
├── css/style.css       界面样式（HUD、氧气条、标题页、商店）
├── js/
│   ├── rules.js        游戏规则：刀、道具、藤壶、金币、关卡（纯逻辑，可单独跑测试）
│   ├── assets.js       自动生成：鲸鱼矢量路径 + 252 个藤壶落点 + 拆出来的手 + 女仆头像
│   └── game.js         渲染和主循环（含动作表 CELEBRATION_MOVES）
├── assets/
│   ├── dafeiyu-front-white.png   人物立绘（保留白底，只裁掉多余空白）
│   ├── dafeiyu-apron.png         围裙上的小鲸鱼徽章（装饰用）
│   ├── hand-a.png                从图二拆出来的右手（备用）
│   └── hand-b.png                从图二拆出来的左手（备用）
├── selftest.html       自检页：打不开或画面不对时先跑这个
└── tests/
    ├── headless.js     无头测试：不开浏览器也能验证规则和经济平衡
    └── run-all.js      一条命令跑完全部检查
```

素材管线在另一个目录（`whale-brand-kit/tools/`）：

```
extract-arms.js      从图二拆手（连通域 + 颜色分类）
build-barnacle-map.js 算藤壶合法落点（用鲸鱼矢量轮廓逐个校验）
pack-game-assets.js  把路径/落点/手/头像打包进 js/assets.js
game-render.js       不开浏览器渲染真实游戏画面（用于检查视觉效果）
game-storyboard.js   把整套动作截成一张分镜图
```
